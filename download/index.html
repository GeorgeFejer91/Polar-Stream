Before first launch

Unsigned research-preview installation

Windows

If SmartScreen appears, choose “More info” and “Run anyway.” The installer is not yet Authenticode-signed.

macOS

Open the DMG and move Polar Stream to Applications. If Gatekeeper blocks it, right-click Open or allow it in Privacy & Security.

Linux

For AppImage, run chmod +x Polar-Stream*.AppImage. Your account needs permission to access the Bluetooth adapter.
