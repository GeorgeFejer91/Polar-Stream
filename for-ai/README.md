# For AI

This directory is the durable control plane for AI-assisted work on Polar
Stream. It explains what the project is, what is true now, where it is going,
how work should be coordinated, and when this context must update.

The root `AGENTS.md` deliberately points every future repository-aware agent
here before code exploration. Humans can use the same material for fast project
orientation.

## Contents

- `START-HERE.md`: required reading order and first actions.
- `GLOBAL-INSTRUCTIONS.md`: repository-wide engineering and safety rules.
- `PROJECT-CONTEXT.md`: durable product and architecture context.
- `ENGINEERING-PRIORITIES.md`: signal-quality, latency, reliability, and
  cross-platform design contract.
- `CURRENT-STATE.md`: verified implementation and release snapshot.
- `GOALS.md`: evolving priorities and completion criteria.
- `ORCHESTRATION.md`: work planning, delegation, ownership, and handoff rules.
- `SELF-UPDATE.md`: triggers and procedure for keeping this folder current.
- `DECISIONS.md`: compact architectural decision log.
- `scripts/`: read-only context and consistency helpers.
- `templates/`: reusable handoff material.

Do not store credentials, participant data, generated telemetry, or speculative
claims in this directory.
